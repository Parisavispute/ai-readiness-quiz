# AI Readiness Score Quiz

A free interactive quiz for engineering students to discover their AI readiness and register for the **"Build Your First AI Project in 60 Minutes"** workshop.

## 🌐 Live Demo
[View on Render](https://ai-readiness-quiz.onrender.com)

## ✨ Features
- 8-question quiz with animated progress bar
- Personalised score out of 105
- Skill gap analysis
- Branch-matched project ideas
- WhatsApp share & clipboard copy
- Mobile-first, dark mode supported

## 🛠️ Tech
Pure HTML + CSS + JavaScript — no frameworks, no backend, no dependencies.
